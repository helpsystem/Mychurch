# 📸 راهنمای تصاویر کلیسا برای اسلایدر

## 🎯 **مسیر فایل‌ها:**
```
public/church-photos/
├── photo1.jpg   (محل پرستش - منبر و صلیب)
├── photo2.jpg   (نور الهی - پنجره شیشه‌ای رنگی با نور)
├── photo3.jpg   (خانه دعا - نمای عمومی کلیسا)
├── photo4.jpg   (صلیب نجات - نزدیک به صلیب)
├── photo5.jpg   (پرستش و ستایش - نمای جلو کلیسا)
└── photo6.jpg   (نمای کلیسا - نمای کامل از بالا)
```

## 📋 **نقشه تصاویر ضمیمه شده:**

بر اساس عکس‌های ضمیمه شده توسط کاربر، این نقشه را دنبال کنید:

### **photo1.jpg** - محل پرستش
- **عکس اصلی**: نمای نزدیک از منبر با صلیب چوبی روی آن
- **آیه**: "زیرا جایی که دو یا سه نفر به نام من جمع شوند، من در میان ایشان هستم." (متی ۱۸:۲۰)
- **فایل منبع**: عکس ۱ یا ۴ از تصاویر ضمیمه (نمای منبر)

### **photo2.jpg** - نور الهی
- **عکس اصلی**: پنجره شیشه‌ای رنگی دایره‌ای با نقش کبوتر
- **آیه**: "من نور جهان هستم. کسی که از من پیروی کند، هرگز در تاریکی راه نخواهد رفت." (یوحنا ۸:۱۲)
- **فایل منبع**: تمام عکس‌های ضمیمه این پنجره رنگی را نشان می‌دهند - از نمای نزدیک استفاده کنید

### **photo3.jpg** - خانه دعا
- **عکس اصلی**: نمای عمومی کلیسا با منبر و صندلی‌ها
- **آیه**: "خانه من خانه دعا خوانده خواهد شد برای همه قومها." (اشعیا ۵۶:۷)
- **فایل منبع**: عکس ۲ یا ۶ (نمای کامل کلیسا)

### **photo4.jpg** - صلیب نجات
- **عکس اصلی**: نمای نزدیک صلیب چوبی روی منبر
- **آیه**: "زیرا خدا جهان را چنان محبت نمود که پسر یگانه خود را بخشید." (یوحنا ۳:۱۶)
- **فایل منبع**: عکس ۱ یا ۴ - crop شده روی صلیب

### **photo5.jpg** - پرستش و ستایش
- **عکس اصلی**: منبر با گیاهان زینتی در کنار
- **آیه**: "با سرودهای شکرگزاری به درگاه او داخل شوید و با ستایش به خانه او وارد گردید." (مزامیر ۱۰۰:۴)
- **فایل منبع**: عکس ۳ (منبر با گیاهان)

### **photo6.jpg** - نمای کلیسا
- **عکس اصلی**: نمای panorama کامل از بالا
- **آیه**: "من نیز می‌گویم که تو پطرس هستی و بر این صخره کلیسای خود را بنا خواهم کرد." (متی ۱۶:۱۸)
- **فایل منبع**: عکس ۵ (نمای پانوراما)

## 🛠️ **نحوه اضافه کردن تصاویر:**

### روش ۱: دستی (توصیه می‌شود)
1. عکس‌های ضمیمه شده را باز کنید
2. هر عکس را با نام مناسب (photo1.jpg تا photo6.jpg) ذخیره کنید
3. در پوشه `public/church-photos/` قرار دهید
4. اطمینان حاصل کنید که همه عکس‌ها فرمت JPG هستند

### روش ۲: با PowerShell
```powershell
# از پوشه اصلی پروژه اجرا کنید:

# عکس 1 - منبر
Copy-Item "path/to/image1.jpg" "public/church-photos/photo1.jpg"

# عکس 2 - پنجره رنگی
Copy-Item "path/to/image2.jpg" "public/church-photos/photo2.jpg"

# عکس 3 - نمای کلیسا
Copy-Item "path/to/image3.jpg" "public/church-photos/photo3.jpg"

# عکس 4 - صلیب
Copy-Item "path/to/image4.jpg" "public/church-photos/photo4.jpg"

# عکس 5 - منبر با گیاهان
Copy-Item "path/to/image5.jpg" "public/church-photos/photo5.jpg"

# عکس 6 - panorama
Copy-Item "path/to/image6.jpg" "public/church-photos/photo6.jpg"
```

## ✅ **بررسی صحت:**

پس از اضافه کردن تصاویر، این کامند را اجرا کنید:

```powershell
Get-ChildItem "public/church-photos" -Filter "*.jpg" | ForEach-Object {
    Write-Host "✓ $($_.Name) - $('{0:N2}' -f ($_.Length / 1MB)) MB"
}
```

باید 6 فایل JPG ببینید.

## 🎨 **بهینه‌سازی تصاویر:**

برای بهترین عملکرد، تصاویر را بهینه‌سازی کنید:

### با PowerShell (نیاز به ImageMagick):
```powershell
# نصب ImageMagick: choco install imagemagick

Get-ChildItem "public/church-photos" -Filter "*.jpg" | ForEach-Object {
    magick $_.FullName -resize "1920x1080^" -gravity center -extent 1920x1080 -quality 85 "$($_.DirectoryName)/$($_.BaseName)_optimized.jpg"
}
```

### یا به صورت آنلاین:
- https://tinypng.com/
- https://squoosh.app/

**اندازه توصیه شده**: 1920x1080px، کیفیت 80-85%, حداکثر 500KB per image

## 🖼️ **پیش‌نمایش در مرورگر:**

پس از قرار دادن تصاویر:

1. سرور را اجرا کنید: `npm run dev`
2. به صفحه اول بروید: `http://localhost:5173`
3. اسلایدر باید تصاویر را با انیمیشن fade نمایش دهد
4. هر 5 ثانیه تصویر عوض می‌شود
5. می‌توانید با دکمه‌های چپ/راست یا نقطه‌های پایین، تصویر را تغییر دهید

## 🔄 **اضافه کردن تصاویر بیشتر:**

برای افزودن تصاویر بیشتر:

1. فایل `components/AIImageSlider.tsx` را باز کنید
2. آیتم جدید به آرایه `CHURCH_IMAGES` اضافه کنید:

```typescript
{
  id: 7,
  title: {
    fa: 'عنوان فارسی',
    en: 'English Title',
  },
  verse: {
    fa: 'آیه به فارسی',
    en: 'Verse in English',
  },
  reference: {
    fa: 'مرجع فارسی',
    en: 'English Reference',
  },
}
```

3. تصویر را با نام `photo7.jpg` در `public/church-photos/` قرار دهید
