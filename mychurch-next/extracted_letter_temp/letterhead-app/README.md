# سیستم نامه اداری و فاکتور (Next.js)

برنامه‌ی Next.js برای تولید **نامه‌های اداری** و **فاکتور** روی **سربرگ شرکت**، با:

- ✅ هدر و فوتر سربرگ (لوگو، نام شرکت، آدرس و اطلاعات تماس)
- ✅ شماره صفحه («صفحه ۱ از ۱» / "Page 1 of 1")
- ✅ دوزبانه (فارسی RTL و انگلیسی LTR) با تعویض زنده
- ✅ حالت چاپ (`@media print`، اندازه‌ی A4)
- ✅ ذخیره‌ی PDF (از طریق دیالوگ چاپ مرورگر → Save as PDF)
- ✅ ارسال سند با ایمیل (nodemailer + SMTP) به‌صورت پیوست HTML
- ✅ فرم ویرایش زنده برای نامه و فاکتور (محاسبه‌ی خودکار جمع، تخفیف، مالیات)

## ساختار پروژه

```
letterhead-app/
├─ app/
│  ├─ page.tsx                 # صفحه اصلی: فرم ویرایش + پیش‌نمایش
│  ├─ layout.tsx              # چیدمان ریشه (RTL)
│  ├─ globals.css            # استایل‌ها + قوانین چاپ
│  └─ api/send-email/route.ts # API ارسال ایمیل (nodemailer)
├─ components/
│  ├─ Letterhead.tsx          # قالب سربرگ (هدر/فوتر/شماره صفحه)
│  ├─ LetterDoc.tsx           # سند نامه اداری
│  ├─ InvoiceDoc.tsx          # سند فاکتور + محاسبات
│  └─ Toolbar.tsx             # دکمه‌های چاپ/PDF/ایمیل + مودال ایمیل
├─ lib/
│  ├─ company.ts              # ⭐ اطلاعات شرکت — اینجا را عوض کنید
│  └─ types.ts                # تایپ‌های داده
├─ public/
│  └─ logo.svg                # لوگوی نمونه — با لوگوی خود جایگزین کنید
├─ preview.html               # پیش‌نمایش ساده (بدون اجرای سرور)
└─ .env.local.example         # نمونه‌ی تنظیمات SMTP
```

## اجرا

```bash
cd letterhead-app
npm install
npm run dev        # http://localhost:3000
npm run build      # ساخت نسخه‌ی تولید
npm start          # اجرای نسخه‌ی تولید
```

## شخصی‌سازی سربرگ

۱. فایل `lib/company.ts` را باز کنید و نام شرکت، آدرس، تلفن، ایمیل، کد اقتصادی و... را وارد کنید.
۲. لوگوی خود را در `public/` بگذارید و مسیر آن را در `company.logo` تنظیم کنید (مثلاً `/logo.png`).
۳. رنگ برند را با `brandColor` و متغیر `--brand` در `globals.css` هماهنگ کنید.

## تنظیم ارسال ایمیل (SMTP)

۱. فایل `.env.local.example` را به `.env.local` کپی کنید.
۲. اطلاعات SMTP خود را وارد کنید:

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM="نام شرکت <your-email@gmail.com>"
```

> برای Gmail باید **App Password** بسازید (نه رمز عادی حساب).

۳. در نوار ابزار روی «✉️ ارسال ایمیل» بزنید، گیرنده و متن را وارد کنید و ارسال کنید.
   سند به‌صورت فایل HTML پیوست می‌شود (در مرورگر/کلاینت ایمیل قابل چاپ و تبدیل به PDF است).

## نکته درباره PDF

روش پیش‌فرض (بدون وابستگی سنگین) استفاده از **دیالوگ چاپ مرورگر → Save as PDF** است که خروجی با کیفیت برداری و فونت فارسی صحیح می‌دهد. اگر تولید PDF کاملاً سمت سرور لازم باشد، می‌توان از `puppeteer` در همان API route استفاده کرد — در صورت نیاز اضافه می‌کنم.

## پیش‌نمایش سریع

فایل `preview.html` را در مرورگر باز کنید تا ظاهر نامه و فاکتور را بدون اجرای سرور ببینید.
