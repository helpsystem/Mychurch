# چک لیست تست جامع Media Library و RBAC (سطوح دسترسی)

زمان اجرا: ۵ تا ۱۰ دقیقه
هدف: تایید نهایی امنیت، سطح دسترسی‌ها و همگام‌سازی گالری با سیستم فایل محلی

## پیش‌نیازها
- [ ] با حداقل دو مرورگر متفاوت (یا حالت Incognito) آماده باشید تا نیازی به لاگین/لاگ‌اوت مداوم نباشد.
- [ ] دسترسی به پنل مدیریت با یک اکانت `Admin`.
- [ ] یک اکانت تستی با نقش `Leader` یا `Operator`.

---

## ۱) تست امنیت و دسترسی‌ها (RBAC)

### سناریو الف: دسترسی Admin (کامل)
- [ ] با اکانت Admin لاگین کنید.
- [ ] بررسی کنید که منوی `Media Library` در سایدبار سمت چپ نمایش داده می‌شود.
- [ ] با کلیک روی لینک، صفحه `/admin/media` بدون خطا و با لیست فایل‌ها باز می‌شود.

### سناریو ب: دسترسی کاربر مجاز (Leader/Operator با تیک Media)
- [ ] در پنل ادمین (بخش `Users & Roles`)، روی آیکون ⚙️ کاربر تستی کلیک کنید و تیک `Media Library` را برای او **روشن** کنید.
- [ ] با اکانت تستی لاگین کنید (یا رفرش کنید).
- [ ] بررسی کنید که منوی `Media Library` در سایدبار وجود دارد.
- [ ] بررسی کنید که صفحه `/admin/media` با موفقیت باز می‌شود و کاربر توانایی آپلود/حذف دارد.

### سناریو ج: دسترسی کاربر غیرمجاز (Leader/Operator بدون تیک Media)
- [ ] مجدداً با اکانت Admin تیک `Media Library` کاربر تستی را **خاموش** کنید.
- [ ] با اکانت تستی صفحه را رفرش کنید. منوی `Media Library` باید از سایدبار حذف شده باشد.
- [ ] **تست نفوذ:** به صورت دستی آدرس `https://your-site.com/admin/media` را در مرورگر تایپ کنید.
- [ ] سیستم باید جلوی ورود را بگیرد و به صفحه `Unauthorized` یا داشبورد ریدایرکت کند. (خطای ۵۰۰ ندهد).

---

## ۲) تست عملکرد کتابخانه مدیا (آپلود و ذخیره‌سازی محلی)

- [ ] در نقش کاربر مجاز یا Admin، وارد Media Library شوید.
- [ ] یک یا چند فایل (عکس و ویدیو) را Drag & Drop کنید.
- [ ] آپلود باید با نوار پیشرفت (Progress Bar) همراه باشد و بدون خطا (سبز رنگ) تمام شود.
- [ ] فایل‌های آپلود شده باید در گرید پایین صفحه نمایش داده شوند.
- [ ] سرور (PM2) را یک بار Restart کنید (`pm2 restart mychurch-next`).
- [ ] صفحه Media Library را رفرش کنید. **فایل‌ها نباید پاک شده باشند** (تایید صحت کارکرد Local Storage).

---

## ۳) تست همگام‌سازی با گالری عمومی (Gallery Sync)

### افزودن به گالری
- [ ] در Media Library روی یکی از تصاویر آپلود شده کلیک کنید تا Modal باز شود.
- [ ] دکمه **«🌐 افزودن به گالری عمومی»** را کلیک کنید. پیام موفقیت باید نمایش داده شود.
- [ ] مودال را ببندید. روی تصویر در گرید باید آیکون کوچک کُره زمین (🌐) ظاهر شده باشد.
- [ ] صفحه اصلی گالری سایت (`/gallery`) را باز کنید. تصویر مورد نظر باید بلافاصله و با کیفیت بالا آنجا اضافه شده باشد.

### حذف از گالری (بدون حذف فایل اصلی)
- [ ] مجدداً روی همان تصویر در Media Library کلیک کنید.
- [ ] دکمه حالا باید تغییر کرده باشد و به شکل **«حذف از گالری عمومی»** باشد. روی آن کلیک کنید.
- [ ] صفحه گالری سایت (`/gallery`) را چک کنید. عکس باید حذف شده باشد.
- [ ] صفحه Media Library را چک کنید. فایل عکس همچنان برای سایر استفاده‌ها (مثل پرستش) موجود است.

### حذف کامل فایل
- [ ] یک عکس را به گالری پابلیک اضافه کنید (مرحله افزودن را تکرار کنید).
- [ ] این بار در Media Library روی دکمه قرمز رنگ **حذف (Delete)** کلیک کنید.
- [ ] فایل از Media Library حذف می‌شود.
- [ ] صفحه گالری سایت (`/gallery`) را چک کنید. عکس باید به طور هوشمند از گالری نیز حذف شده باشد تا لینک خراب تولید نشود.

---

## معیار قبولی (Pass Criteria)
- [ ] هیچ لینک شکسته‌ای (Broken Image) در Media Library یا Gallery وجود ندارد.
- [ ] هیچ کاربری بدون تیک صریح `Media Library` در بخش Users نمی‌تواند وارد گالری ادمین شود.
- [ ] هیچ فایل آپلودی با ری‌استارت شدن سرور از دست نمی‌رود.

## در صورت بروز خطا ثبت شود:
- متن خطا / لاگ PM2
- عکس از وضعیت فایل‌های موجود در دیتابیس (Supabase -> `gallery_images`)
