Broadcast Console Guide v2.4.0

Step-by-step instructions for operating the Sanctuary Broadcast Console during live service days. Includes camera switching, overlay management, and stream health monitoring.

mobile_arrow_right

Initializing the Stream

Before initiating the broadcast to external platforms (YouTube, internal RTMP), ensure that the local OBS bridge is connected and receiving video data from the sanctuary cameras.

// Verify RTMP status
$ sanctuary-cli stream status --env=production

// Expected Output:
// [OK] RTMP Server active on port 1935
// [OK] Audio sync latency: 12ms
warning

Pre-flight Checklist

Always verify audio levels in the Dante controller before clicking "Go Live". The console will warn you if levels are below -40dB, but visual confirmation is mandatory.

waves

Managing Presentation Overlays

Overlays (lyrics, sermon notes, lower thirds) are managed via the left sidebar in the Broadcast view. They are synchronized with the Sanctuary Presentation Mode.

  • check_circle Lyrics Overlay: Auto-advances based on the Presentation Operator's cues.
  • check_circle Translation Subtitles: Toggle dual-language mode (EN/FA) using the `Alt+T` shortcut.
